# Dennis Alexandry - Portfolio

Personal branding site and CV for Dennis Alexandry, Data & Analytics Manager in Jakarta.

Single static page: `index.html`. No build step, no dependencies. Fonts load from Google Fonts.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Deploy

Any static host works (Vercel, GitHub Pages, Netlify). Point it at the repository root.

## Notes

- Work cards use illustrative sketches, not real screens or data.
- Client names and internal figures are intentionally omitted.
